01 / Installation

Set up
on Windows

Forge comes as a ZIP: ScotMillfieldForge_<version>.zip. A .vst3 is a folder. It runs in every DAW on Windows 10 or 11 (64-bit) that loads VST3 instruments – the steps are the same everywhere. Windows only for now; a macOS version is in the works. Load new versions in a test project only.

01Close your DAW. Otherwise an existing plugin file is locked.Applies to every update
02Unzip and copy the folder ScotMillfieldForge.vst3 to C:\Program Files\Common Files\VST3\.Needs administrator approval · delete an old ScotMillfieldWorkbench.vst3 if present
03Start your DAW and let it scan for new plugins. Forge shows up as the VST3 instrument “Scot & Millfield Forge” by “Scot & Millfield”.Not listed? Rescan in the DAW’s plugin settings, make sure it uses the VST3 system folder, and check its blocklist
04Create an instrument track with Forge and open “Furnace” on the start page.The project stores module, view, preset and window size
Imported audioTo keep dragged files safe inside the project, let your DAW copy imported audio files into the project folder – most DAWs offer this in their preferences or when importing. Furnace writes its files to %TEMP%\SM-Forge\ and clears them after seven days.

02 / Magic Mode

Roll
a riser

A new Furnace starts in Magic Mode: click the cube and it rolls a complete riser for you. You only choose length and direction – no key, no knobs. Switch to Advanced whenever you want to shape every detail.

What a roll does

  • Every section gets new values within musical ranges – noise colour, volume, filter sweep, LFO, ducking, auto-pan, phaser or comb, a second noise layer, space, delay and the end. Some sections are switched off at random, so the rolls really differ.
  • Never a tone: Magic risers are noise-based, so they fit any key.
  • Levelled: each roll is rendered once and its sources and volume curve adjusted so the peak sits at about −8 dBFS. The output gain always stays at its protective −6 dB.
  • Length and direction stay as you set them, before or after the roll.
  • Every roll has a number. The same number always gives the same riser; the name “Magic 48213” also shows in the preset bar.

Keep, go back, refine

  • History: ‹ › go back to the last ten rolls of the session.
  • Save … in the preset bar keeps a roll as your own preset.
  • Advanced (top right) shows all sections with the rolled values – change anything, then switch back to Magic if you like. Your changes stay.
  • Every roll reaches your DAW as one parameter change – undoable with Ctrl+Z where the DAW supports plugin undo – and the project remembers mode, roll and sound.

03 / Advanced Mode

Advanced
Mode

A riser lives not only from getting louder and brighter, but from movement in the sound. Furnace describes every moving target as a curve from start to end. This is the Advanced Mode, where every section can be edited. Hover or tap a number to see what it does.

Triggering

  • MIDI note: every note restarts the riser. The length comes from Length, not from the note length. Furnace is monophonic.
  • Preview: plays the riser without a note, on the Root. While it plays, the button reads Stop.
  • Root: sets the pitch of the tone layer for preview and export (default C3). A played MIDI note overrides it. The root note belongs to the song and is not stored in presets.

Locked to the project

  • While the transport runs, Furnace follows the song position (PPQ) – tempo automation included. The riser ends exactly on the target bar; the start is sample-accurate.
  • Without transport (stopped, or standalone) Furnace counts time at the host tempo. In the standalone version you set the tempo by dragging.
  • If playback jumps back (cycle) or by more than one bar, the riser stops with a short fade.

Direction

Up is the classic riser. Down turns it into a downlifter: every curve runs backwards – bright and loud first, dark and quiet at the end. Switching changes the default length from 8 to 2 bars.

Curves

Every moving target has a start value, an end value and a curve shape between −1 and +1. Positive values rise slowly first, then fast (the typical riser); negative ones the other way round. Cutoff, frequencies and rates move logarithmically, volume in dB, pitch in semitones. The knob pairs in the sections set start and end; the shape is dragged at the middle handle in the curve view.

Focus

  • The tab decides: all fifteen curves are drawn, but only those of the open tab are in colour with handles – Volume always, as a reference. The rest lie faintly behind.
  • Grey out by hand: click a legend entry to grey that curve out; its handles are locked, so the others are easy to grab. Ctrl+click shows only that one curve in colour.
  • Overlapping handles: touch a knob pair in a section, and its curve comes to the front – its handles win where several lie on top of each other.
  • Each start/end pair in the sections has a dot in the colour of its curve.

Controls

  • Knobs: drag vertically, Ctrl + drag for fine steps, double-click resets to the default, the mouse wheel steps.
  • Segment controls (length, filter type …): click a segment.
  • Every change reaches your DAW as a parameter change: automatable, and undoable where the DAW supports it. All sound parameters appear in the automation as “Furnace …”, e.g. “Furnace Cutoff End” – the curve shapes too (“… Curve”).
  • Bypass: the power switch in the head of a section switches it off. Bypassed sections are dimmed but stay editable.

04 / Tab Sound

Source, filter,
volume

The source with its volume envelope first, then the optional layers on top: Noise, Volume, Tone, Filter – sections 01 to 04. Noise and tone run through the filter together.

05 / Tab Modulation

LFO, ducking,
stereo

Movement in time: an accelerating LFO, pumping on the project grid and a stereo image that swings faster and faster. Sections 05 to 07.

06 / Tab Texture

Movement
in the sound

The wandering hiss and a second layer that comes in later – so the riser does not just get louder, it lives. Sections 08 and 09.

07 / Tab Space & End

Space, delay,
end

The riser opens up towards the end. And it either stops hard on the bar – or rings out with a tail. Sections 10 to 12.

Fixed low cut at 40 HzAt the very end of the chain – after reverb and delay, before Gain and Soft Clip – a high-pass filter removes everything below 40 Hz with 24 dB per octave. It protects subwoofers from sub rumble and DC, is always on and has no control. Above about 80 Hz the sound is unchanged; preview and export are filtered identically, the ring-out tail included.

08 / Export

Onto the
audio track

Preview = export: the file comes from the same engine with the same seed as the preview – identical sample by sample.

How it works

  1. Shape the sound. Furnace re-renders in the background 0.3 s after the last change (“Rendering …”, then “Ready”).
  2. Drag the tile Drag to audio track onto an audio track in your DAW – ideally to the start of a bar.
  3. Or use Save as … for a copy anywhere you like.

The file

  • WAV, 24 bit, stereo, no normalisation. If the peak is above 0 dBFS, it is shown in red.
  • Project tempo and sample rate (standalone: 48 kHz). Sample-accurate length: bars × beats per bar × 60 / BPM × sample rate, plus the tail with Ring Out.
  • Name: Riser_8Bars_124BPM_A2_Tonal-Supersaw_1.wav – bars, tempo, root note, preset, seed.
  • Always free of sub rumble: the fixed low cut at 40 Hz (24 dB/octave) acts on the file too.

Tempo automation

The export uses a fixed tempo. If the project tempo changes during playback, the waveform says so: for the exact length, render (bounce) the instrument track to audio in your DAW – during playback the riser follows tempo automation precisely anyway.

09 / Presets

Factory presets &
your own sounds

Presets store the sound, not the song: the root note stays when you load one. All factory presets stay below 0 dBFS.

Classic Noise Up8 barsThe classic noise riser: the low-pass opens from 150 Hz to 16 kHz, a light LFO, phaser and reverb grow towards the end.
Wobble Riser16 barsResonant low-pass with an LFO accelerating from 1/2 to 1/32 – the wobble turns into a shimmer before the drop.
Tonal Supersaw8 barsA seven-voice supersaw pad rises one octave, noise in the background, wide reverb. Plays on the root note.
Short Noise Sweep4 barsA short band-pass sweep with phaser and auto-pan – for transitions within a part.
Downlifter2 barsDirection Down: from bright and loud to dark and quiet, the reverb rings out for one bar.

Your own presets

  • Save … stores the current sound under a name in User Presets. Same name → it asks before replacing.
  • Location: Documents\Scot & Millfield Forge\Presets\Furnace as XML – Open Preset Folder in the menu takes you there.
  • Delete only works on your own presets; the current sound stays as it is.
  • The project remembers the last preset loaded; its name also goes into the file name of the export.

10 / Tips

When something
gets stuck

Waveform is a flat line

The riser is very quiet or silent – often both cutoff points sit at the bottom. Double-click the handles in the curve view or load a factory preset.

No sound on preview

In the standalone version, choose an output device under “Options” (Windows Audio is fine). In your DAW: instrument track selected, with monitoring or record-arm on.

Riser stops in cycle

On purpose: when playback jumps back, Furnace stops and restarts with the next note. Put the note at the start of the cycle range.

Window too small

Drag the window anywhere from 900 × 600 to 1600 × 1000. If it is too low, the page scrolls instead of squeezing.
